# Release v1.2.0

## Changes
- Added DHW quota exclusive duty-cycling: when domestic hot water is the only
  reason the pump runs (no room heating demand), quota runs are now capped at a
  configurable max duration and separated by a configurable pause, spreading
  water heating evenly across the day instead of one continuous morning block.
- New helpers:
  - `input_number.dhw_exclusive_max_run_min` — max continuous DHW-only run
    (default 45 min, 0 disables duty-cycling)
  - `input_number.dhw_exclusive_pause_min` — pause between DHW-only runs
    (default 90 min, 0 disables duty-cycling)

## Behavior
- Room-demand pump starts are never delayed by the DHW pause.
- `min_pump_on` / `min_pump_off` compressor-protection timers always take
  precedence over the new limits.
- Setting either helper to 0 restores the previous continuous-run behavior.

## Upgrade Notes
- Add the two new helpers (via the updated
  `packages/heat_orchestrator_helpers.yaml` package or manually) and restart
  Home Assistant, then reload AppDaemon. Without the helpers the app falls back
  to the built-in defaults (45/90 min).
